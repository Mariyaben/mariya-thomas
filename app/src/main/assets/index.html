Clock settings

Mariya is fixed to IST (UTC +05:30), regardless of either phone’s time zone. Thomas is currently set to start 5 hours 30 minutes behind IST. Use Set difference to correct it, or ±1 hour for ship adjustments.

Install on iPhone

1. Open this link in Safari. If you opened it inside WhatsApp, use its menu to open in Safari.

2. Tap Share → Add to Home Screen.

3. Turn on Open as Web App if shown, then tap Add.

4. Open the new M & T icon. Select Thomas, then pair Chat using Mariya’s code.

Install before pairing. Safari and the installed app may use separate storage. Clocks work offline after the first load. Chat needs internet and the app open; iPhone widgets and background chat notifications aren’t included.

On Android or desktop, use your browser’s Install app option.
